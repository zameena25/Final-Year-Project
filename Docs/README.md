# Ransomware Detector and Preventor

## Overview
This repository contains coursework and development artifacts for a final-year undergraduate capstone project. It includes source code, documentation, testing scripts, and reports produced throughout the project lifecycle.

## Repository Structure
- `docs/` – Project reports, proposals, and architecture diagrams  
- `detector/` – Code modules for monitoring system behavior  
- `preventor/` – Modules for handling potential threats  
- `gui/` – Graphical interface files  
- `tests/` – Testing scripts and simulated scenarios  
- `logs/` – Sample logs generated during testing
